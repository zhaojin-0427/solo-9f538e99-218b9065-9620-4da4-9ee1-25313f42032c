# 档案词频阅览包

外馆拿到档案词频后，需要能**按词找到对应的扫描页**。本工具提供两个页面：

- **制包首页**：把一套 **页×词** 词频矩阵及配套的页键、词表 CSV 制成**单文件阅览包**（ZIP）；
- **阅览页**：上传阅览包后输入词（可选填起始页键），按页键顺序列出该词的前 100 个
  非零页及计数，并标明有无后续。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

本地开发（Python 3.11+）：

```bash
pip install -r app/requirements.txt
python app/app.py          # http://localhost:8000
```

运行测试：

```bash
python3 -I tests/run_tests.py
```

`examples/` 下有一套小样例（含重复词、重复坐标、显式 0、全零页与全零词），
`examples/big/` 有一套 650 页的较大样例（hot 词跨块、可翻页），均可直接上传试用。

## 输入格式

| 文件 | 说明 |
| --- | --- |
| `matrix.mtx` | Matrix Market 通用整数坐标格式：`%%MatrixMarket matrix coordinate integer general`，注释行以 `%` 开头，维度行 `行数 列数 非零项数`，其后每行 `行号 列号 计数`（编号从 1 开始，计数为非负整数）。行对应页、列对应词 |
| `pages.csv` | 页键单列 CSV（UTF-8、无表头、每行一个），顺序与矩阵行一一对应，**页键唯一** |
| `words.csv` | 词表单列 CSV，顺序与矩阵列一一对应；词**允许重复**（同词的多列将按原口径合计） |

合计口径：重复坐标、同词的多列都合计；未写出的坐标按 0 计；合计为 0 的坐标
（只可能来自显式写出的 0）不存入包中。

## 阅览包格式

单文件 ZIP，内含：

- `manifest.json` —— 格式与版本、排序后的页键表与词表、非零记录总数，以及每个
  数据块的成员名、记录数、SHA-256 和块内分段（词、记录数、词频合计、首末页键）；
- `blocks/NNNNNN.z` —— 数据块，**每块最多 512 条非零记录**，独立压缩、可独立解压；
  记录按（词, 页键）排序，JSON 行格式（每行 `["页键", 计数]`），**一词可跨块**。

制包规则：

- 页键、词按字符串排序后重新组织；词表去重（全零词保留在词表中）。
- 制包全程流式读写，**内存占用不随非零项数增长**（见下节）。
- 包先写入 `.part` 临时文件，完整生成后原子改名，**只有完整的包才可下载**。

## 查询规则

- 输入词，可选填起始页键：按页键顺序**从头**或**从起始键之后**（不含起始键本身）
  列出前 100 个非零页及计数，并标明有无后续；有后续时页面给出“下一页”链接。
- **词表中没有的词**与**全卷计数为零的词**（在词表中但任何页都没有非零记录）
  分别提示；起始页键不在本卷页键表中时也会明确指出。
- 查询**只解压本页结果所需的数据块**：按清单中各分段的首末页键跳过不需要的块，
  攒够 100 条结果（外加 1 条用于判断有无后续）即停。
- 所需块**缺失**或未通过 **CRC / SHA-256 完整性校验**时**整页报错**；
  无关的块损坏不影响查询。

## 内存设计

制包与查询的内存占用**不随非零项数增长**：

- 矩阵条目流式解析后批量写入磁盘上的 SQLite；
- 合计与排序由 SQLite 在磁盘完成（`temp_store=FILE`，排序溢出到临时文件）；
- 聚合结果按（词, 页键）流式读出，每攒满 512 条压缩成一个数据块写入 ZIP；
  块清单先落临时文件，最后流式并入 `manifest.json`；
- 查询时任意时刻只解压当前所需的一个块（≤512 条记录）。

只有页键表、词表驻留内存（随页数/词数增长）。测试：100 万条输入的制包用例，
Python 侧内存峰值 < 64 MB。

## 配置（环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `WORK_DIR` | `app/work`（容器内 `/data/work`） | 临时工作目录；下载包与已上传阅览包的存放目录 |
| `DOWNLOAD_TTL_SECONDS` | `3600` | 下载链接与已上传阅览包的有效期 |
| `SQLITE_TMPDIR` | 系统默认（容器内 `/data/tmp`） | SQLite 排序临时文件目录 |
